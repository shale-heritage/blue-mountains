## How to Apply Changes to Zotero (Manual Process)

### Current Workflow (No Automation)

Since no automated application scripts exist, all changes must be applied manually:

#### Step 1: Understand the Hierarchy

Use `poly_hierarchy_additions.csv` to understand tag relationships:

```bash
# View hierarchy for a specific tag
grep "Hotel" data/poly_hierarchy_additions.csv

# Result:
Hotels,Hotels,hierarchy,parent=Accommodation buildings
Hotel,Hotel,hierarchy,parent=Hotels
Carrington Hotel,Carrington Hotel,hierarchy,parent=Hotel
```

#### Step 2: Apply to Zotero Manually

1. **Open Zotero** and locate the item(s)
2. **Consult reports** for item-specific instructions
3. **Apply tags** manually:
   - Add new tags as specified
   - Remove deprecated tags (e.g., generic "Accommodation")
   - Zotero automatically creates tags when you type them

#### Step 3: Track Progress

Create a tracking spreadsheet:

```csv
Report,Items,Completed,Status
accommodation_rationalization,64,0,"Not started"
alcohol_rationalisation,12,0,"Not started"
hotel_licensing,13,0,"Not started"
```

Update as you work through each report.

## Future: Automated Application (Planned)

### Why No Automation Yet?

From `docs/api-integration.md`:

> **For future read-write scripts (vocabulary publishing):**
> - Name: "Blue Mountains - Read Write"
> - Permissions: **Read/Write**
> - Implementation: Phase 4 (planned)

**Reason:** Current scripts use **read-only** API keys following principle of least privilege. Writing to Zotero requires:

1. Read-write API key configuration
2. Application script development (not yet built)
3. Testing framework (avoid accidental damage to library)
4. Rollback mechanism (in case of errors)

### Proposed Automated Workflow (Future)

```python
# Pseudocode for future script: scripts/34_apply_tag_changes.py

def apply_tag_changes(csv_file, zotero_api_key_readwrite):
    """
    Apply tag changes from CSV to Zotero library.

    WARNING: Requires read-write API key. Use with caution!
    """

    # Load changes from CSV
    changes = load_csv(csv_file)

    # For each change:
    for change in changes:
        if change['action'] == 'hierarchy':
            # Apply parent-child relationship (Zotero doesn't natively
            # support hierarchies, so this would need special handling)
            pass
        elif change['action'] == 'synonym':
            # Rename tag (find all items with old tag, replace with new)
            rename_tag(change['old_tag'], change['new_tag'])
        elif change['action'] == 'merge':
            # Merge tags (add new tag to all items with old tag, remove old)
            merge_tags(change['old_tag'], change['new_tag'])

    print(f"Applied {len(changes)} changes to Zotero library")

def rename_tag(old_tag, new_tag):
    """Rename tag across all items."""
    items = zot.items(tag=old_tag)  # Get all items with old tag

    for item in items:
        # Remove old tag
        item['data']['tags'] = [t for t in item['data']['tags']
                                if t['tag'] != old_tag]
        # Add new tag
        item['data']['tags'].append({'tag': new_tag})
        # Update item in Zotero
        zot.update_item(item)
```

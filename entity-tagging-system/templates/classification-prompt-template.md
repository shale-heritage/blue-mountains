# Entity Classification Prompt Template

**Purpose:** Standardized prompt for Claude entity-classifier skill to classify dual-nature entities as building, organisation/business, or both.

**Usage:** Replace `{PLACEHOLDERS}` with actual values, then paste into entity-classifier skill.

---

## Template

```
I need you to classify {COUNT} mentions of {ENTITY_TYPE_PLURAL} in text from archival historical sources.

For each mention below, determine whether the {ENTITY_TYPE_SINGULAR} should be classified as:
- **building** (Built Environment facet only)
- **business/organisation** (Agents facet only)
- **both** (polyhierarchical - appears in both facets)

Apply the entity classification heuristic, looking for spatial indicators (at/in/near, events occurring, accommodation) vs agency indicators (ownership, operations, services, financial actions).

Please analyse each mention independently and provide the structured output format specified in the skill.

---

{MENTIONS_BLOCK}
```

---

## Placeholders

- **{COUNT}**: Number of mentions (e.g., "18")
- **{ENTITY_TYPE_PLURAL}**: Plural form (e.g., "schools of arts", "hotels", "churches")
- **{ENTITY_TYPE_SINGULAR}**: Singular form (e.g., "school of arts", "hotel", "church")
- **{MENTIONS_BLOCK}**: Auto-generated by script 38, formatted as:

```
## Mention N

**Entity:** {entity_name}
**Item:** {item_title} ({item_date})
**Trove URL:** {url}

**Context:**
> {extracted_context}

---
```

---

## Automated Generation

The prompt is automatically generated by:

```bash
venv/bin/python scripts/38_classify_entities_with_claude.py --entity-type {type}
```

Output saved to: `data/entity_classification/{type}_classification_prompt.txt`

---

## Entity-Classifier Skill Invocation

After generating the prompt:

1. Invoke the entity-classifier skill:
   ```
   /skill entity-classifier
   ```

2. Paste the generated prompt

3. Wait for structured classification output

4. Save output to: `entity-tagging-system/outputs/{entity-type}/{entity-type}_classification_results.md`
